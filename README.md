# Prompt Petri

> Culture your prompts like bacteria and watch mutation produce useful mutants.

An AI playground that takes a base prompt and grows a petri dish of mutated variants. You select strains by tone, length, and task fit, then compost failures into better future prompts.

## Features
- Seed a base prompt and generate a petri dish of eight mutant variants
- Compare mutants by tone, length, confidence, and failure smell
- Run A/B test batches on a small eval set of sample tasks
- Save failed mutants to a compost report that suggests stronger traits

## Stack
- Next.js
- OpenAI
- PostgreSQL
- Recharts

## Getting started
```
npm install, create .env.local with OPENAI_API_KEY and DATABASE_URL, run npm run db:migrate, then npm run dev.
```
